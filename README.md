- **ضيف:** يتدرب دون حساب، وتُمسح تجربته عند التحديث أو الإغلاق. لا تُحفظ نتائجه دائمًا ولا تُنقل إلى حساب لاحق.
- **إنشاء حساب:** يكتب الطالب اسمه وأي بريد إلكتروني وكلمة مرور يختارها للموقع وتأكيدها. لا يوجد اشتراط Google أو قائمة موافقة مسبقة.
- **حساب:** له تخزين محلي معزول ومزامنة سحابية مع كشف تعارض الأجهزة. لا يُعلن نجاح حفظ سحابي عند تعذر المزامنة؛ راجع حالة الحفظ قبل الإغلاق.
- **مدير:** حساب المالك `ayobalbtoosh41@gmail.com` المرتبط بـ UID ثابت على الخادم، ويراجع بيانات الطلاب وتقدمهم ونتائجهم وإجاباتهم ونشاط الدخول المنقّى، ويعطل الحسابات أو يعيد تفعيلها. لا يقرأ كلمات المرور.

كلمة المرور تخص المنصة؛ لا يُطلب من الطالب إدخال كلمة مرور بريده. للإعداد المباشر المطلوب، يُوقف Confirm email بعد ربط المدير بنجاح؛ لذلك إنشاء حساب بالبريد لا يثبت ملكية صندوق البريد أو الهوية المدرسية. إيميل مماثل أو صلاحية مكتوبة في المتصفح لا يمنحان الإدارة.

**خطوة التفعيل للمشروع الموجود:** تشغيل ترقية 003 مرة واحدة بعد 001 أو 002، ثم Email ON وAllow signup ON وConfirm email OFF، وضبط رابط الموقع. لا يلزم إنشاء Supabase من جديد أو إعداد Google Cloud. الدليل الكامل في [AUTH_SETUP.md](AUTH_SETUP.md)، وضوابط الخادم في [supabase/README.md](supabase/README.md). لا تضع مفاتيح خدمة أو كلمات مرور في المشروع.

## الألعاب والمحتوى

الأوضاع الـ11 متاحة، مع ست واجهات فعلية: اختيار فردي، صح/خطأ، إجابات متعددة، توصيل، ترتيب، وفراغ بخيارات. الامتحان 45 دقيقة إجمالية مع رجوع وتعديل وتسليم مؤكد. المواجهة على جهاز واحد بالتناوب والاستعداد، وعدد محدد لكل لاعب.

4 وحدات، 26 درسًا، 2340 سجلًا سليم البنية، 2314 متاحًا للعب، و26 مسودة مستبعدة محفوظة. عنوان الفئة الظاهر «توجيهي»؛ **مصدر البنك الفعلي كتاب الصف الحادي عشر/الفصل الثاني**. المقارنة الدلالية مع الكتاب عينة 52 سؤالًا، والفحص اللفظي الآلي شمل كامل البنك؛ لم يُدّعَ اعتماد علمي شامل. راجع [QUESTION_BANK_AUDIT.md](QUESTION_BANK_AUDIT.md) و[CONTENT_COVERAGE.md](CONTENT_COVERAGE.md).

## تشغيل المطور والبناء

يتطلب البناء Node.js 24 الموصى به، أو 22.8 فأحدث، وnpm:

```sh
npm ci
npm run build
npm start
```

الخادم على المنفذ 4173. على Windows افتح PowerShell داخل مجلد المشروع ونفّذ الأوامر نفسها بعد تثبيت Node.js؛ لا يلزم VS Code للتشغيل. `index.html` و`standalone.html` و`dist/index.html` ملفات مولّدة، تشمل بيانات الأسئلة وعميل Supabase الرسمي المجمّع محليًا دون CDN. عدّل ملفات `src` ثم أعد البناء.

النسخة المستقلة مناسبة للتدريب كضيف. استخدم الموقع عبر HTTP/HTTPS للحسابات والمزامنة؛ لا يعتمد التسليم على استمرار الحفظ أو الاتصال السحابي في `file://` عبر جميع المتصفحات. لا توجد PWA أو مواجهة عبر الإنترنت.

## الاختبارات

```sh
npm test
npm run build
npm start
# في نافذة أخرى:
npm run test:browser

```

إذا لم يوجد Chromium، نفّذ `npx playwright install chromium`. يمكن تحديد `CHROMIUM_PATH`. اختبارات الحسابات المحاكية وSQL المحلي لا تثبت نجاح التسجيل على خدمة Supabase المستضافة. اختبارات الألعاب التي تستخدم حسابًا اصطناعيًا لا تحول الضيف الحقيقي إلى حساب دائم. النتائج الحالية والتاريخية وحدودها في [TEST_RESULTS.md](TEST_RESULTS.md)، وأدلة الخادم في مجلد `supabase`.

## الملفات الرئيسية

- `src/core.js`: الأسئلة والدوران والنقاط.
- `src/storage.js`: تخزين الضيف والحسابات وعزل النطاقات.
- `src/auth.js`: تسجيل الحساب والدخول والمزامنة والإدارة عبر SDK الرسمي.
- `src/controller.js`: الجلسات والمؤقت والامتحان والتهيئة.
- `src/ui.js` و`src/styles.css`: الواجهات العربية ولوحة الإدارة والمظهران.
- `config/auth.public.json`: عنوان المشروع والمفتاح العام فقط؛ لا أسرار إدارة.
- `supabase/`: ترحيلات SQL والسياسات والتوثيق والاختبارات؛ 001 و002 وأدوات قائمة البريد ملفات تاريخية وليست مطلوبة لتسجيل الطالب الحالي.
- `data/`: البنك الكامل والمؤهل والمسودات وأدلة المراجعة.
- `reference/original.html`: الملف الأصلي للمقارنة.
- `tests/` و`test-results/`: الاختبارات والأدلة مع تمييز المحاكاة عن الخدمة الفعلية.

## النشر والخصوصية

المستودع الحالي `ayoubalbtoosh/islam`؛ فرع المصدر `accounts-setup`، وفرع الاستضافة `gh-pages`. انشر محتوى `dist` إلى مصدر Pages. ولـVercel استخدم Other / `npm run build` / `dist`، ثم حدّث Site URL وعناوين العودة إلى رابطك النهائي.

Supabase Auth يدير كلمات المرور؛ لا تحفظها المنصة في التقدم أو النسخ الاحتياطية أو لوحة المدير. يرى المدير معلومات الطالب التعليمية التي أعلن عنها نموذج التسجيل، ضمن عرض خادمي منقّى، وليس كائنات Auth السرية أو رموز الجلسات. إيقاف تأكيد البريد لا يثبت ملكيته. لا تجمع المنصة تقدم الضيف. يتطلب اعتماد المحتوى للتقويم الرسمي مراجعة معلم المادة؛ لا تكفي الفحوص البنيوية واللفظية.
