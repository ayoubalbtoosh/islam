## الملفات الرئيسية

- `src/core.js`: الأسئلة والدوران والنقاط.
- `src/storage.js`: تخزين الضيف والحسابات وعزل النطاقات.
- `src/auth.js`: تسجيل الحساب والدخول والمزامنة والإدارة عبر SDK الرسمي.
- `src/controller.js`: الجلسات والمؤقت والامتحان والتهيئة.
- `src/ui.js` و`src/styles.css`: الواجهات العربية ولوحة الإدارة والمظهران.
- `config/auth.public.json`: عنوان المشروع والمفتاح العام فقط؛ لا أسرار إدارة.
- `supabase/`: ترحيلات SQL والسياسات والتوثيق والاختبارات؛ 001 و002 وأدوات قائمة البريد ملفات تاريخية وليست مطلوبة لتسجيل الطالب الحالي.
- `data/`: البنك الكامل والمؤهل والمسودات وأدلة المراجعة.
- `reference/original.html`: الملف الأصلي للمقارنة.
- `tests/` و`test-results/`: الاختبارات والأدلة مع تمييز المحاكاة عن الخدمة الفعلية.

المستودع الحالي `ayoubalbtoosh/islam`؛ فرع المصدر `accounts-setup`، وفرع الاستضافة `gh-pages`. انشر محتوى `dist` إلى مصدر Pages. ولـVercel استخدم Other / `npm run build` / `dist`، ثم حدّث Site URL وعناوين العودة إلى رابطك النهائي.

## المواجهات الأونلاين — 2.4

- افتح «مواجهة أونلاين» بعد الدخول بحساب الإيميل، أنشئ غرفة، وأرسل رمز الدعوة أو رابطها لصديق يدخل بحساب مختلف.
- خمسة أسئلة مشتركة و90 ثانية تبدأ عند انضمام اللاعب الثاني. يُحسب الوقت والنقاط على PostgreSQL، وتُحفظ النتيجة تلقائيًا وتظهر في لوحة المدير «نتائج المواجهات الأونلاين».
- الإغلاق أو انقطاع الاتصال لا يوقف الوقت. العودة بالحساب نفسه ثم فتح المواجهات تستعيد الغرفة. إلغاء غرفة الانتظار والانسحاب أثناء اللعب مدعومان.
- تبقى حسابات الإيميل والتقدم الفردي كما هي؛ نتائج الأونلاين في جداول مستقلة، ولا تُكتب فوق ملف التقدم.
- لا تتطلب الميزة Edge Functions أو Realtime أو خدمة مدفوعة؛ تستعمل RPC كل3ثوانٍ أثناء عرض غرفة نشطة، وتوقف الطلبات عند إخفاء الصفحة مع تراجع عند انقطاع الشبكة. تنطبق حصص مشروعSupabase المجاني المعتادة.

**تفعيل المشروع الموجود:** طبّق `supabase/migrations/004_online_duels.sql` في SQL Editor بعد003. يتضمن بنكًا من104 أسئلة مراجعة من26 درسًا؛ لا يحتاج مفاتيح خدمة في المتصفح. اقرأ `supabase/ONLINE_DUELS.md` لعقد API والحدود وإدارة السجل.


## لون الخلفية —2.4.1

من الإعدادات، اختر لون الخلفية المخصص ثم «حفظ الإعدادات». تتوفر معاينة فورية وزر للخلفية الافتراضية، وتتأقلم ألوان النص مع اللون المختار. يُحفظ اللون داخل إعدادات الحساب الحالية ويعود بعد إعادة الفتح؛ إعداد الضيف يبقى مؤقتًا. تبديل المظهر من الشريط العلوي يعيد الخلفية الافتراضية للمظهر. لا يحتاج هذا التعديل ترقيةSQL جديدة.

اختبارات هذه الإضافة: `npm test` و`npm run test:background` مع خادم `npm start`، وتشمل الحفظ والاستعادة والتنقل والتباين والعودة للافتراضي ومقاس الهاتف. الدليل `test-results/background-ui-results.json`؛ الاختبار بحساب محاكاة محلي وليس إثباتًا لمزامنةSupabase المستضافة.


## ألوان الصفحة والقائمة من الشريط العلوي —2.4.2

اضغط رمز لوحة الألوان بجانب الشمس والحساب. اختر لون خلفية الصفحة ولون خلفية القائمة كلًّا على حدة؛ يُحفظ كل لون تلقائيًا عند اعتماد الاختيار، وتتوفر إعادة الافتراضي لكل خلفية دون تغيير الأخرى. ألوان القائمة تشمل القائمة الجانبية وقائمة التنقل السريع على الهاتف، مع نصوص تتأقلم مع لونها. يُغلق صندوق الألوان بالنقر خارجه أوEscape أو زر الإغلاق. إعدادات الحساب تحفظ اللونين عبر المسار الحالي دونSQL جديد؛ اختيار الضيف مؤقت.
