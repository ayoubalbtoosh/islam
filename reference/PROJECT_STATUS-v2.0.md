# حالة المشروع

الإصدار: 2.0.0 • تاريخ التسليم: 4 نوفمبر 2026 بتوقيت الرياض.

## المنفذ

- أُعيد تنظيم الموقع المرفق إلى مصادر منفصلة مع نسخة HTML مستقلة ونسخة إنتاج ثابتة.
- صُممت رئيسية جديدة زمردية/ذهبية، وخريطة وحدات وصفحات دروس، وتنقل للهاتف والكمبيوتر، ومظهران وصفحة حول المنصة.
- أصلحت قواعد الامتحان 45 دقيقة واختياراته، والانتقال التلقائي والإجابات المركبة، وتناوب اللاعبين وتكافؤ العدد والنقاط، والدوران دون تكرار داخل الجولة.
- الحفظ متوافق مع اسم قاعدة النسخة القديمة، مع معاملات ذرية، ونسخ احتياطي متحقق منه ومؤكد، وتاريخ إنجازات، وحماية الجولة الجارية.
- الأعداد من البيانات الحقيقية؛ لا بيانات طلاب وهمية. نتائج المواجهات منفصلة عن XP الطالب وإحصاءاته.
- أُصلحت عيوب اكتشفت أثناء الاختبار، منها حد epoch الذي كان يمنع استعادة جلسات صحيحة، وتجاهل نطاق الوحدة في مراجعة الأخطاء.

## بيانات المحتوى

4 وحدات، 26 درسًا، 2340 سجلًا، 2314 مؤهلًا للعب، 26 مسودة مستبعدة محفوظة. قورنت عينة 52 سؤالًا مع PDF، وأجري 62 تعديلًا موثقًا في 28 سؤالًا. لا زيادة مصطنعة في العدد. مرشحو التشابه بين الأسئلة الـ51 باقون لمراجعة المعلم. وقورن نص الصفحات آليًا لكل 2340 سؤالًا؛ 938 حالة ضعيفة التشابه مع نص الصفحة تحتاج مراجعة، ولا يثبت هذا الفحص الآلي صحة أو خطأ المعنى.

## ما لم يُنجز أو لم يُثبت

- **اعتماد علمي وديني بشري كامل للبنك لم يُنجز.** لا يُعامل المشروع كاختبار رسمي موثق لكل المحتوى قبل ذلك.
- فتح `file://` مباشرة محجوب بسياسة Chromium المُدار في البيئة. الحزمة المستقلة نفسها اختُبرت دون طلبات خارجية، لكن فتحها المباشر على Windows لم يُختبر.
- لا اختبار على Safari/Firefox أو هاتف فعلي، ولا تدقيق WCAG أو تدقيق اختراق مستقل شامل.
- حماية تعدد التبويبات تتطلب Web Locks؛ السياقات غير الداعمة تعرض تنبيهًا ويجب الاقتصار فيها على تبويب واحد.
- لا مزامنة سحابية ولا مواجهة عبر الشبكة ولا PWA؛ ليست ادعاءات للمنتج.
- ملفات Vercel جاهزة، **لم يحدث نشر أو push**، ولا يوجد عنوان منشور.

## مسارات المتابعة

1. للعرض المدرسي التقني: افتح نسخة الإنتاج بخادم محلي، واستعمل اسمًا مستعارًا؛ اختبر درسًا، مواجهة، وامتحانًا ثم استعرض الإحصاءات والإنجازات.
2. لاعتماد المحتوى: راجع `CONTENT_COVERAGE.md` وملفات data مع معلم المادة، بدءًا من المسودات ومرشحي التشابه والأسئلة غير المراجعة.
3. للتوزيع العام: أجر اختبار Windows/المتصفحات الأخرى، وراجع المحتوى قبل النشر على Vercel حسب README.

نتائج التنفيذ النهائية الوحيدة المعتمدة موجودة في `TEST_RESULTS.md` و`artifacts/browser-results.json`. الصور أدلة بصرية على تلك النسخة وليست نتائج طلاب حقيقية.
