# تفعيل 005 من SQL Editor بأجزاء صغيرة

استخدم [صفحة النسخ خطوة بخطوة](https://ayoubalbtoosh.github.io/islam/setup-online.html). إذا لم تظهر الصفحة بعد، افتح ملفات هذا المجلد واضغط Raw لنسخ كل ملف كاملًا.

الملف الكامل `migrations/005_educational_online.sql` كبير على SQL Editor. البديل المكافئ هنا يحتوي12جزءًا، وكل استعلام أقل من60000بايت.

## الترتيب

1. `00_schema.sql`: الجداول والدوال. يتطلب تطبيق004 سابقًا في المشروع الحالي.
2. `01_content.sql` ثم02ثم03ثم04ثم05ثم06ثم07ثم08ثم09ثم`10_content.sql`.
3. `99_verify.sql`: فحص الاكتمال والصلاحيات. يجب أن يظهر `educational_online_status = ready` و`required_activity_rows_verified = 2179`.

في SQL Editor استبدل النص القديم كله بجزء واحد فقط، ثم اضغط Run. بعد ظهور Success انتقل إلى الجزء التالي. لا تجمع الأجزاء في استعلام واحد. يمكن استعمال نافذة SQL نفسها لكل الأجزاء.

إذا توقفت أو ظهر خطأ، يمكن إعادة الأجزاء من البداية؛ كل ملف محتوى معاملة مستقلة ويحدّث السجلات نفسها دون تكرارها. اكتمال الجزء00 وحده أو بعض أجزاء المحتوى لا يعني اكتمال التفعيل. لا تختبر الألعاب الجديدة قبل نجاح الفحص الأخير.

لا تغيّر هذه النسخة الحسابات أو ربط المدير أو تقدم الطلاب، ولا تحذف الغرف والنتائج السابقة. تختصر تكرار السؤال نفسه داخل ملفات النقل ثم تعيد إنشاء جميع2179سجلًا ببيانات مطابقة للترقية الأصلية.

## إعادة التوليد والاختبار للمطور

```sh
node scripts/split-educational-online.mjs
npm run build
npm run test:sql-editor
```

البناء يعيد توليد الأجزاء وصفحة النسخ تلقائيًا. الفحص المحلي يطبق كل جزء باستعلام مستقل، ويقارن محتوى جميع السجلات بالأصل، ويتحقق من رفض التثبيت الناقص وإعادة المحاولة وحفظ بيانات طالب وغرفة سابقة. هذا ليس تأكيدًا لتطبيقها على Supabase المستضاف.
