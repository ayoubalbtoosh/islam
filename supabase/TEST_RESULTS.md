الأمر المنفَّذ من مجلد المشروع:


هذه اختبارات SQL وأدوار وRLS ومحفّزات ودوال حقيقية، مع **جداول Auth ومطالبات JWT مصغرة للاختبار**. لا تثبت إصدار رمز Supabase أو التحقق من توقيعه، ولا تفحص خدمة Auth مستضافة.

لم تُنفَّذ بسبب عدم وجود مشروع Supabase وبيانات اعتماد مزوّد Google وحسابات اختبار مقدمة:

- نشر الترحيل والخطاف على Supabase وفحص التوافق مع مخطط Auth الموجود في المشروع الفعلي.
- تسجيل دخول حقيقي ببريد وكلمة مرور، وإرسال الدعوة أو تأكيد البريد أو رابط إعادة التعيين.
- تحويل GoogleOAuth الحقيقي وموافقة المستخدم وربط هوية Google بحساب Email.
- اختبار خطاف Before User Created ضمن إعداد خدمة Auth الفعلي، لا مجرد استدعاء دالته.
- تشغيل اتصالات سحابية متزامنة من جهازين. ثبت رفض الإصدار القديم في PostgreSQL المحلي، وتستخدم الدالة قفلًا لكل مستخدم، لكن لم يُنفذ اختبار اتصالين سحابيين متوازيين.
- انتهاء الرموز وإبطال جلسة Supabase وسلوك الشبكة الحقيقية. تعطيل القائمة المسموحة والتحقق من البريد اختُبرا محليًا مع مطالبات سابقة.

**قرار الجاهزية:** مخطط الخادم وتعليمات التهيئة واختبارات الصلاحيات المحلية جاهزة للمراجعة؛ تشغيل حسابات المدرسة فعليًا يتطلب إعداد مشروع صاحب المنصة وإكمال اختبار Email وGoogle من طرف إلى طرف. لا يوجد ادعاء نشر أو نجاح دخول سحابي في هذه النتائج.
